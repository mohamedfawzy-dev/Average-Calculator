# Average Calculator

A simple Average Calculator built with C++.

## Features
- Accepts multiple numeric values.
- Calculates the sum and average.
- Validates that the number of values is positive.
- Allows the user to restart the program.

## How to Run
1. Compile `AverageCalculator.cpp` using a C++ compiler.
2. Run the generated executable.
3. Enter the number of values.
4. Enter each value to calculate the average.

## Example
```text
Enter the Number of values -> 3
Enter the Value num 1 -> 10
Enter the Value num 2 -> 20
Enter the Value num 3 -> 30
The Average = 60 / 3 = 20
```
